# Templates

Starter files for new projects. Copy, fill in the `[PLACEHOLDERS]`, delete what doesn't apply.

| File | Use for |
|---|---|
| `PROJECT-INSTRUCTIONS.md` | Baseline for a Claude project's instructions: working loop, shared folder, safety, quick-start |
| `CLAUDE.md` | Repo context file for Python projects |
| `CLAUDE-web.md` | Repo context file for Next.js + Supabase projects |
| `ROADMAP.md` | The path: goal, status, milestones, "not now" list, issues, log |
| `SPEC.md` | The current step only: milestone, tasks, "done when" checks, rollback, verification |
| `project-structure.md` | Folder layout, `pyproject.toml`, ruff/pytest/pre-commit config for Python projects |
| `web-project-structure.md` | Folder layout, env handling, and config for Next.js + Supabase projects |
| `ci/web-ci.yml` | GitHub Actions: lint, typecheck, test, build for web projects |
| `ci/python-ci.yml` | GitHub Actions: ruff + pytest for Python projects |

**Where each kind of fact lives** (one home per fact): how we work → project instructions · repo facts → `CLAUDE.md` ·
the path → `ROADMAP.md` · the current step → `SPEC.md`.
